**1. What is a Promise?**
A Promise is an object that represents the result of an asynchronous operation. It has three states: pending, fulfilled, and rejected.

---

**2. What are localStorage, sessionStorage, and cookies?**

* **localStorage**: Stores data with no expiration (persistent).
* **sessionStorage**: Stores data for a single browser session.
* **Cookies**: Small data stored and sent with every HTTP request; can have expiration.

---

**3. Why do we need HTTP?**

HTTP is a protocol used for communication between client (browser) and server to transfer data like web pages, APIs, etc.

---

**4. What is the `this` keyword?**

`this` refers to the current execution context (object) depending on how a function is called.

---

**5. How do websites fake statefulness if HTTP/HTTPS are stateless?**

Using techniques like cookies, sessions, tokens (JWT), and local storage to maintain user state across requests.

---

**6. How do you flatten a nested array?**

Using methods like `flat()` or recursion. Example: `arr.flat(Infinity)`.

---

**7. What are CRUD operations?**

* Create
* Read
* Update
* Delete

---

**8. What is a Closure?**

A closure is a function that remembers variables from its outer scope even after the outer function has executed.

---

**9. Difference between HTTP and HTTPS?**

* **HTTP**: Not secure, data sent in plain text
* **HTTPS**: Secure, data encrypted using SSL/TLS

---

**10. What is the window object in DOM?**

The window object is the global object representing the browser window and provides access to DOM, BOM, and APIs.

---

**11. Explain Web Client Architecture**

It is a structure where client (browser) sends requests, server processes them, and sends responses (typically client-server model).

---

**12. Difference between Higher Order Function and Callback?**

* **Higher Order Function**: A function that takes another function as argument or returns a function
* **Callback**: A function passed as an argument to another function**
